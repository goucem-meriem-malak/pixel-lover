## The story

| Step | What happens |
|---|---|
| 1 | Pick **Player 1 (Boy)** or **Player 2 (Girl)** and type your name. It floats over your head in the game. |
| 2 | **The boy** is a knight on an **earth** world. He plays levels 1 to 10 and collects **coins**. |
| 3 | After level 10 he walks to the castle flag and sits down. In the **ring shop** he spends his coins on one of five rings. |
| 4 | The game creates a room on Firebase and shows a 6-character **invitation code**. He sends it to her. |
| 5 | **The girl** is a princess on a **cloud** world. She types her name and the code, the game checks the room, and she plays levels 1 to 10. She collects **flowers**. |
| 6 | On her level 10 she finds the knight waiting. He takes off his helmet, **kneels on one knee**, opens the ring box and says **HAPPY BIRTHDAY LOVE!** She says thank you. Hearts, a kiss, **TOGETHER FOREVER**, and both names on screen. |

## Features

- **Flag slide.** At the end of every level you grab the flagpole and slide down while the flag comes down, then walk to the castle.
- **Real platformer feel.** Coyote time, jump buffering, variable jump height, stomping, one-way platforms. Pixel-perfect camera so the art never shimmers.
- **Bump the blocks.** Jump under a `?` block or a brick and it bumps. `?` blocks give coins (boy) or flowers (girl), and bricks break.
- **Enemies.** Cats in four colours, low-crawling green and purple **turtles** (stomp one and kick its shell), hopping **frogs** (ribbit!), and **piranha plants** that pop out of the pipes. The boy's levels have extra and faster enemies.
- **Power-ups, for her only.** The first **wings elixir** gives the princess a pair of **wings** (just for looks, she still walks). The next elixir, a **fire flower**, lets her throw **fireballs** from a Fire button.
- **Two worlds.** Earth with hills, bushes and green pipes for him. A pastel sky of clouds, rainbows and pink pipes for her.
- **A ring to earn.** The boy's coins buy five rings, from a free clover ring to a diamond. Prices scale with the coins in the game, so the choice is always fair.
- **Names.** Both players type a name. It floats above the character in a small pixel font.
- **Ten levels, rising difficulty.** The boy's levels are a lot harder than the girl's. Levels are generated from a fixed seed, so level 7 is always the same level 7. Every gap and step stays inside the jump range, so every level can be finished.
- **Two phones, one story.** The invitation code lives in Firebase Realtime Database, so the two players can be anywhere.
- **Offline demo mode.** Without Firebase the whole story still runs on one device, which is handy for testing.
- **Touch controls** (Left, Right, Jump, Fire) and keyboard controls in the Editor. Works with both Unity input systems.

## Tech stack

| Part | Choice |
|---|---|
| Engine | Unity 2D (C#), tested layout for Unity 2021.3 LTS and later, including Unity 6 |
| Backend | Firebase Realtime Database (free Spark plan) |
| Art | Generated pixel art (Python + Pillow), embedded as base64, no imports |
| UI | Code-built uGUI with a custom 5x7 pixel font |
| Target | Android (iOS should work, but is untested) |

No server code and no paid plan are needed.

## Quick start

You need [Unity Hub](https://unity.com/download) with a Unity LTS editor and the **Android Build Support** module, and an Android phone.

1. Create a new **2D** project, then copy these folders from this repository into the project's `Assets` folder:
   `Scripts`, `Editor`, `Icons`.
2. Create an empty scene, add an empty GameObject called `Game`, and add the **GameBootstrap** component to it. Press **Play**.
3. *(Optional, for two phones)* set up Firebase. Create a Realtime Database, paste [`Firebase/database.rules.json`](Firebase/database.rules.json) into its **Rules** tab and publish it, import the Firebase Unity SDK, add `google-services.json`, and add the scripting define `FIREBASE_ENABLED`.
4. **Build And Run** on your phone.

The full walkthrough, with every click, is in [docs/SETUP.md](docs/SETUP.md).

### Testing quickly

Tick **Debug Skip Button** on the `LevelManager` component and a **SKIP >>** button appears in the HUD, so you can jump straight to level 10 for either character.

## Project structure

```
Assets/
  Scripts/
    GameBootstrap.cs       entry point: put it on one empty GameObject
    UIManager.cs           start menu, names, ring shop, invitation code, HUD, touch buttons
    LevelManager.cs        builds levels, flow for boy and girl, level 10 finale
    LevelGenerator.cs      the ten levels (deterministic, rising difficulty)
    PlayerController2D.cs  movement, jump, ground check, power-ups, fireballs
    Enemies.cs             cats, turtles, frogs, piranha plants
    Blocks.cs              ? blocks, bricks, wings elixirs, fire flowers, fireballs
    EndingCutscene.cs      the surprise: kneel, ring, happy birthday, kiss, names
    FirebaseManager.cs     6-character codes, create and verify rooms
    NameTag.cs             the little name above each character
    SpriteFactory.cs       decodes the embedded art, pixel font renderer
    PixelArtData.cs        all sprites (generated)   PixelFontData.cs  font (generated)
    GameData.cs, Effects.cs, LevelObjects.cs, CameraFollow2D.cs
  Editor/AppIconSetup.cs   sets the crown as the app icon
  Icons/                   app icon (and adaptive icon layers)
Firebase/database.rules.json   paste into the Firebase console
Tools/                         the Python scripts that draw all the art
docs/                          logo, sprites, screenshots, setup guide
```

## App icon

The crown in `Assets/Icons/` becomes the app icon automatically when you open the project (it runs once). It fills the classic, round **and adaptive** Android icons with padding so the crown is never cropped. To re-apply it, use the menu **Pixel Love > Apply App Icon**, rebuild, and uninstall the old app first so the phone refreshes its icon.

## Rebuilding the art

```bash
pip install pillow
python Tools/generate_art.py
```

This rewrites the sprite PNGs in `docs/sprites/` and the two generated C# files. `python Tools/make_sheet.py` rebuilds the cast picture above.
